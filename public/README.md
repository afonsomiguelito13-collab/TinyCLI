# 🦁 Tiny Cloud CLI

**O teu agente de programação autónomo, direto no terminal.**

O Tiny Cloud CLI é uma ferramenta de linha de comandos (CLI) leve e inteligente, desenhada especificamente para rodar em ambientes como **Termux (Android)**, Linux e macOS. Ele não é apenas um chat: ele tem **poderes de agente** para criar ficheiros, executar comandos no terminal e testar código Python em tempo real.

*"Benchmarks are honest."*
